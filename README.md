# homebrew-tap

Homebrew formulae for tools I maintain.

```sh
brew install Gaurgle/tap/pinz
```

`brew tap Gaurgle/tap` resolves to this repository: Homebrew strips the
`homebrew-` prefix, so the tap name is `Gaurgle/tap` while the repository is
`Gaurgle/homebrew-tap`.

## Formulae

| Formula | What it is |
|---|---|
| [`pinz`](Formula/pinz.rb) | A spatial bulletin board in the terminal: post-it notes on a pannable, zoomable board |

Every formula here is generated by the tool's own release workflow and copied in
on release. Do not hand-edit one: the next release overwrites it. For `pinz` the
generator is `packaging/homebrew/render-formula.sh` in
[Gaurgle/pinz](https://github.com/Gaurgle/pinz).
